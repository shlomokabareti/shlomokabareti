# Shlomo Kabareti

I'm the founder and CEO of [Vortex](https://vortex.nyc). Vortex is the financial infrastructure agents depend on to move money.

These are open-source projects powered by Vortex infrastructure. We build them in public for three reasons:

1. **They're big enough problem spaces to matter** — and I'm committed to solving them. Contributions welcome, always.
2. **They dogfood Vortex** — real production load lets us test features before releasing them publicly.
3. **I genuinely love building for the dev community.**

## Projects

- **[Veil](https://github.com/VortexNYC/veil)** — agent-first credential broker: agents use secrets without ever seeing them. Go, Postgres, Ory.
- **[Pile](https://github.com/VortexNYC/pile)** — agent-native workspace OS: issues, docs, support, and chat in one surface. Cloudflare Workers, D1, Durable Objects.
- **[Seal](https://github.com/VortexNYC/seal)** — open-source e-signature platform (DocuSign/PandaDoc alternative). Cloudflare Workers, free for personal use.
- **[convex-auth](https://github.com/VortexNYC/convex-auth)** — Convex-native auth runtime for production apps.
- **[better-auth-ui](https://github.com/VortexNYC/better-auth-ui)** — auth UI components and React Email templates for Better Auth.
